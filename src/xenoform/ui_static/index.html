How the cut is made

The desk pings /system_stats on this address. ComfyUI on this machine is http://127.0.0.1:8188.

LTX-2.3 is the default core. LTX-2.5 is local open weights under the LTX-2.x Community License, free under $10M annual revenue. If that distilled file is missing, or the open-weights check fails, the cut stays on LTX-2.3. Turbo stays on LTX 0.9.5, and an 8 GB card stays on 0.9.5 unless you pick 2.5. Partner nodes stay out.

Dry run is the default. It renders the liquid body, slices it on the script, and passes those slices through — no weights, no GPU. Live sends each slice through the Comfy SDK to the local proxy on port 8189. This URL stays the ComfyUI health ping.

Off by default. This covers FLUX 3 API, H3 API, partner nodes, and cloud LLMs. The demo, the judges page, and setup never need it.

Off by default. On, Simple mode shows Cloud quality: LTX-2.5 morphs rendered by a paid Comfy partner node, billed to your Comfy account after a price card and a confirm click. The default path is 100% open weights and never needs this.
