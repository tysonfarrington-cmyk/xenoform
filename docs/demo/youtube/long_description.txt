The full tour of Xenoform, the open-source music video director built on ComfyUI: drop in a song, pick a vibe, and one object morphs into the next on every beat.

It covers the song and vibe, the idea line, Make, the morph engine (five morph styles, three timings, effects that ride the kick), editing on the timeline, your own film clips, sharing, and how it is built underneath: stems, the shot plan, LTX-Video morphs through the Comfy Python SDK, MIDI and an MCP server. Open weights by default, all local.

Code (MIT): https://github.com/tysonfarrington-cmyk/xenoform
