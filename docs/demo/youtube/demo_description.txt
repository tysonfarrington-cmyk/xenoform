Drop in a song, pick a vibe, and Xenoform makes a music video where every beat is a transformation: one object morphs into the next, right on the music.

Xenoform is an open-source music video director built on ComfyUI. It reads the song's beats, sections and drop, splits the stems, plans the shots, and renders a chain of LTX-Video morphs, then lets you edit the result like a timeline. Open weights by default, all local, built on the Comfy Python SDK, with MIDI and an MCP server so any AI can direct it.

Code (MIT): https://github.com/tysonfarrington-cmyk/xenoform
